# Number Tidy — ファイル名の先頭番号を整理

GitHub Pages に置くだけで動く、インストール不要のファイル名番号整理ツールです。

## できること

例えば次のファイルを選ぶと、先頭の番号だけを連番にして ZIP で保存できます。

| 変更前 | 変更後 |
| --- | --- |
| `1_1 朝の音楽.mp3` | `1 朝の音楽.mp3` |
| `1_2 夜の音楽.mp3` | `2 夜の音楽.mp3` |
| `2 お気に入り.mp3` | `3 お気に入り.mp3` |
| `3 ライブ音源.mp3` | `4 ライブ音源.mp3` |

- **タイトルと拡張子はそのまま**です。音楽ファイル自体を加工したり再エンコードしたりしません。
- **先頭番号の数値順**で並べ替えて、1 から番号を振ります。開始番号と 0 埋め桁数を変更できます。
- `1`、`01`、`1_2`、`1-2`、`1.2`、`１_２` などに対応します。
- 番号のないファイルは **変更せず ZIP に含めます**。
- 複数フォルダを選んだ場合は、標準で **フォルダ単位の連番**になります。チェックを外すと選択したファイル全体で通し番号になります。
- ファイル本体はサーバーにアップロードしません。ブラウザ内だけで処理します。
- ZIP は非圧縮（保存方式）です。MP3 などでは再圧縮の利点が少なく、元データをそのまま保存します。

## GitHub Pages に公開する方法

1. GitHub に新しいリポジトリを作成（例: `Number-Tidy`）。公開リポジトリがおすすめです。
2. このフォルダの **`index.html`** をリポジトリの直下にアップロードして Commit します。
3. GitHub の **Settings → Pages** を開き、**Build and deployment → Deploy from a branch** を選択します。
4. **Branch: `main` / `/(root)`** を選んで Save します。
5. 公開された `https://<GitHubユーザー名>.github.io/Number-Tidy/` を開きます。

公開するページは `index.html` **1ファイルだけ**で動きます。HTML ファイルをPCで直接開いて試すこともできます。

## 使い方

1. 「ファイルを選択」「フォルダを選択」、またはドラッグ&ドロップで対象を指定します。
2. プレビューで「変更前 → 変更後」を確認し、必要に応じて開始番号や桁数を設定します。
3. 「整理したZIPをダウンロード」を押します。
4. ZIP を解凍すると、名前が整理されたファイルを取り出せます。

> **安全上の仕様:** ブラウザから元ファイルを直接リネームせず、整理済みのコピーをZIPとしてダウンロードします。元のフォルダへの上書き・削除は行いません。

## 注意点

- 先頭が番号以外（例: `タイトル1.mp3`）のファイルは番号整理の対象外です。
- ファイルの**タイトル部分によるソートは行いません**。同じ番号を持つ複数ファイルは選択時の順序を維持します。
- 重複する出力名が発生する場合は安全のためダウンロードを停止します。
- ZIP形式の仕様上、現バージョンは合計4GB未満、ファイル数65,535以下が対象です。
- ファイル選択で渡されたフォルダの階層は維持しますが、空のフォルダはZIPに含まれません。
- フォルダのドラッグ&ドロップは Chrome / Edge など Chromium 系ブラウザ向けです。ブラウザによっては「フォルダを選択」を使ってください。
- `1.2` などの小数点を含む数字は、`1`、`2` の階層番号として比較します。例: `1.9` の次は `1.10` です。

## ローカル開発

編集するのは `index.html` だけです。外部CDNや依存ライブラリは使用していません。
