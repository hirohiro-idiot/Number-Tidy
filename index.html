#
Number Tidy
名前を整える、シンプルな道具。
FILE NUMBER ORGANIZER

先頭の番号だけ、
きれいな連番に。

「1_1、1_2、2、3...」のように並んだファイルを「1、2、3、4...」へ。タイトルも拡張子も変更せず、番号だけを振り直します。

BEFORE / 変更前

1_1 朝の音楽.mp3
1_2 夜の音楽.mp3
2 お気に入り.mp3
3 ライブ音源.mp3
➜

AFTER / 変更後

1 朝の音楽.mp3
2 夜の音楽.mp3
3 お気に入り.mp3
4 ライブ音源.mp3

1. 整理するファイルを選ぶ

⇧
ここにファイルやフォルダをドロップ
音楽・画像・文書など、種類は問いません
🔒 ファイルは外部に送信しません。
このページを開いているブラウザ内だけで処理します。元ファイルも変更しません。

2. 連番の設定

対象にする番号の例
1、01、1_2、1-2、1.2、１_２（全角数字にも対応）
並べ替えルール
タイトルを無視して先頭番号を数値順に並べ、1から振り直します。番号のないファイルはそのまま残します。

3. 変更内容を確認

ファイルを選択すると、ここにプレビューが表示されます。

0件0件変更0件対象外
変更前変更後状態
ファイルがまだ選択されていません。

※ ダウンロードはZIP形式です。ZIPを解凍すると整理済みのファイル名になります。

準備中...

音声の末尾加工

番号整理とは独立した機能です。音声をブラウザ内で加工し、元ファイルは変更しません。出力はMP3または16-bit PCM WAV（元のタグ・ジャケットは保持しません）。

MP3は44.1kHzで再エンコードします。初回のMP3加工時のみ外部CDNから lamejs 1.2.1 (LGPL-3.0) を読み込みます。音声の送信は行いません。WAVは外部ライブラリ不要です。
